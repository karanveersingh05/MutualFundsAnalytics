01 — THE IDEA

One market. Multiple lenses.

Mutual fund performance is more than a single return number. This project builds a repeatable analytical path from source files to comparative metrics, risk analysis and investor-level patterns.

A / 01

From datasets to usable signals

Ten core CSV datasets cover fund metadata, NAV history, AUM, SIP flows, category flows, folio counts, scheme performance, transactions, holdings and benchmark indices.

INGEST · CLEAN · VALIDATE
A / 02

A structured analytical core

A SQLite database organised around fund and date dimensions with fact tables for NAV, transactions, performance, portfolio holdings and AUM.

SQLITE · STAR SCHEMA
A / 03

Analysis with context

Performance metrics are read alongside downside risk, benchmark sensitivity, concentration, SIP behaviour and portfolio allocation trade-offs.

COMPARE · INTERPRET · REPORT

05 — THE POINT OF THE WORK

Useful analysis begins with better questions.

Which fund delivered a return, and what risk accompanied it? How did flows change over time? Where is a portfolio concentrated? What assumptions sit behind a projected outcome?

This project is an attempt to turn those questions into a practical, inspectable analytics workflow rather than a single ranking table.
